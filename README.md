Privacy Policy – Smart Image Downloader

Smart Image Downloader does not collect, store, transmit, or share any personal or sensitive user data.

All image processing and conversion is performed locally within the user’s browser. The extension does not track browsing activity, log user actions, or communicate with external servers except to fetch image data explicitly selected by the user for download.

No analytics, advertising, or third-party tracking services are used.

If you have questions, you may contact the developer via the Chrome Web Store support section.
